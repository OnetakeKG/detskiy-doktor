# Детский доктор

Обучающая пиксельная игра: симулятор приёма педиатра. Задавайте вопросы, осматривайте,
назначайте обследования, ставьте диагноз по МКБ-10 и выбирайте тактику. Иногда случается
«голубой код» — экстренная ситуация, где нужно оказать помощь по алгоритму.

Случаи составлены по клиническим рекомендациям Минздрава РФ и материалам ВОЗ.
Игра обучающая и не заменяет консультацию врача.

## Как играть
- В браузере: откройте `index.html` или страницу GitHub Pages.
- На Windows: `Play.bat` — откроет игру в отдельном окне.
- На iPhone: откройте страницу в Safari → «Поделиться» → «На экран „Домой"».

## Как добавить случай
Случаи лежат в `cases*.js`. Скопируйте любой блок и измените данные.
После изменения файлов увеличьте `VERSION` в `sw.js`, чтобы телефоны получили обновление.
